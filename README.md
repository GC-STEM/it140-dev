# IT-140 Code Repository

> [!IMPORTANT]
> 🚨 **README:** Do **NOT** fork or clone this repository yet. Follow the instructions below.

Welcome to the **IT-140 Code Repository**! To get started:

* Complete the one-time [**setup tasks**](#-1-1-setup-tasks) before the end of Week 1.
* [**Get help**](#-help-and-support) early and often, if you run into problems.
* To complete assignments, open your local repo when Brightspace directs you to the [**code repository**](#️-repository-assignments).
* [**Learn more**](#-learn-more) about what you are doing and why, if you are curious.

---

## 💻 1-1 Setup Tasks

Complete these one-time setup tasks before starting [Repository Assignments](#️-repository-assignments), preferably before the end of Week 1. Return here after each task.

1. [**Set up your GitHub account**](https://github.com/GC-STEM/cs-core/wiki/GitHub)
    * **New account**: Click on the above link to create and configure a new account.
    * **Existing account**: Click on the above link to configure your existing account.

2. [**Set up your course development environment**](https://github.com/GC-STEM/it140-dev/wiki/Course-IDE)

3. [**Fork this repository to your GitHub account**](https://github.com/GC-STEM/it140-dev/wiki/Fork-Repo)

4. [**Clone your forked repository to your course development environment (CDE**](https://github.com/GC-STEM/it140-dev/wiki/Clone-Repo)

5. [**Open the repo in your IDE**](https://github.com/GC-STEM/it140-dev/wiki/Open-IDE)

If a setup task does not work as expected, [get help](#-help-and-support) before continuing.

> [!IMPORTANT]
> Now that you have completed the setup tasks, perform all remaining repository assignments in your course development environment (CDE, not on GitHub.

---

## 🏗️ Repository Assignments

If Brightspace sent you to GitHub, switch to your local copy of the repository in your course development environment (CDE. If you are using the recommended course development environment (CDE, open a terminal, type the following command, and press **Enter**.

```bash
code "$HOME/Repos/it140-dev"
```

Find the matching **Guidelines & Rubric** below. Open the corresponding **Repository Assignment** and follow the instructions. They will guide you through the listed templates and deliverables. If the instructions are unclear or something does not work as expected, [get help](#-help-and-support) early.
